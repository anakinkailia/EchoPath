# 60-second product demonstration

Before presenting: run `npm run dev`, open the home page, use a clean browser profile, and keep the fictional example autofill ready. No external credentials are required. Say clearly: **“This demonstration uses fictional records and deterministic preparation templates, not live AI.”** When demonstrating a configured live integration, say so only after verifying it works.

| Time   | Action                                                                 | Suggested narration                                                                                                                                                          |
| ------ | ---------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 0–10s  | Show homepage.                                                         | “Job descriptions tell us the title. EchoPath helps students understand the work, the challenges, and what to practice before day one.”                                      |
| 10–20s | Share experience → Fill fictional demo example → Continue three times. | “Contributors answer a guided set of questions, review their account, choose privacy, and give permission to share.”                                                         |
| 20–30s | Check consent → Submit → See experience & template insights.           | “The original account stays intact. Here the template organizes its actual skills and lessons. Our server integration can use OpenAI structured extraction when configured.” |
| 30–45s | Explore experiences → search SQL → choose Northstar Labs.              | “Search and combined filters reveal practical experience behind a role. This lesson is specific: agree on metric definitions before querying.”                               |
| 45–60s | Build my preparation roadmap → Build my roadmap → check a milestone.   | “Selected experiences inform a weekly plan. Source links show the supporting advice, and general preparation exercises are labeled. Progress saves for the next visit.”      |

Finish with the product tagline: **“Real experiences. Smarter next steps.”** Invite judges to try the flow and use Give feedback. Do not claim the fictional examples were interviews, that templates were AI-generated, or that local demo submissions reached other users.

For a live AI demonstration, prepare a real consented contribution in your own Supabase project, verify extraction and moderation beforehand, and publish it using trusted administration. AI latency is variable, so precompute approved insights and have the honest demo fallback available. No fake loading delays are used.
